# MiniQue 3D Babaszoba Tervező

Interactive 3D nursery room planner developed for MiniQue, allowing users to visually design and customize a baby room directly in the browser.

## About the project

The application was created as a custom web-based room planning solution for the MiniQue baby webshop.

Users can build and customize a nursery using real products, furniture and decorations, helping them visualize how different items and layouts work together before purchasing.

The project is continuously developed with a focus on usability, responsive design and an intuitive visual planning experience.

## Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
- Responsive Web Design
- JSON product data
- Git & GitHub

## Key features

- Interactive 3D nursery room
- Multiple editable walls
- Real MiniQue products
- Furniture and decoration placement
- Drag & drop functionality
- Object resizing and rotation
- Layer management
- Wall customization
- Door and window placement
- Undo / Redo functionality
- Mobile-friendly interface
- Saved room designs
- Product summary
- Quote request functionality

## Project structure

- `index.html` – main planner interface
- `3d.html` – 3D room planner
- `css/` – application styles
- `js/` – planner functionality
- `data/` – product and configuration data
- `images/` – product and room assets
- `generate-products.js` – product data generation

## Purpose

The goal of the project is to connect e-commerce with interactive interior planning, allowing customers to design a complete nursery and visualize MiniQue products in a realistic room environment.
